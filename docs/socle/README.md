# Socle — 18 leçons

Phase préalable au programme « Vibe Coder Professionnel », pour quelqu'un qui
reprend les bases depuis le début. Chaque leçon est une page autonome avec une
console JavaScript intégrée : rien à installer, utilisable depuis un téléphone.

Le socle remplace la phase de réactivation de 10 jours, qui supposait des bases
seulement rouillées.

## Méthode

- **Prédire avant d'exécuter.** L'effort de prédiction est ce qui fait
  apprendre ; lire la réponse ne fait presque rien.
- **Écrire le code soi-même.** Pendant tout le socle, l'IA est un tuteur, jamais
  un exécutant. C'est ce qui construit la capacité à juger, plus tard, le code
  qu'elle produira.
- **Plafond de 20 minutes.** Bloqué plus longtemps : demander l'explication, pas
  la solution, noter la question, avancer.
- **Une leçon n'est finie** que lorsque les questions de fin trouvent leur
  réponse sans remonter dans la page.
